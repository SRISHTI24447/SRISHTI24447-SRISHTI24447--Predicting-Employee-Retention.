## 🧠 Problem Statement

The goal is to build a predictive model that identifies employees who are at risk of leaving the organization. The model helps HR make informed decisions to reduce turnover and improve retention strategies.

---

## 📊 Techniques Used

- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Dummy Variable Creation and Feature Scaling
- Feature Selection using Recursive Feature Elimination (RFE)
- Logistic Regression Model
- Model Evaluation using Accuracy, Precision, Recall, AUC-ROC
- Optimal Cutoff Identification using ROC Curve

---

## ✅ Assumptions

- The dataset is a reliable representation of the organization's employees.
- Business context remains stable for predictions to hold.
- Missing and inconsistent data have been handled appropriately.
